How it works

An alloy of your engineering data

  1. 1

    Connect, read-only

    Alloy Catalog reads your CAD files and ERP data. It never changes a CAD file.

  2. 2

    Extract

    Properties, parameters, materials, mass, previews, BOMs, assembly structure, drawing title blocks and parts lists.

  3. 3

    Fuse

    One record per part number. Every fact keeps its source, gaps stay empty instead of guessed, and conflicts between sources are flagged.

  4. 4

    Find, ask, build

    Search and browse, ask the AI agent, or connect your own tools and agents through the API.

Features

Built around the part number

One page per item

Preview, key facts, BOM, where-used, drawings, files, revisions and ERP data on a single page, each fact linked to the file or record it came from.

Search that understands structure

Facets, numeric ranges and relation filters such as "used in an assembly that…", plus a command palette for jumping straight to any part.

An AI agent that cites

Ask in your own language. The agent finds, counts and compares across the whole catalog and links every part and document it mentions.

Clean master data

Classes based on ISO 14224, IEC 81346 and ECLASS, typed attributes with completeness, tags and shared lists. Similar parts and variants are linked automatically.

Open to your tools

A JSON API, exports and an MCP server let your own applications and AI agents read the catalog under the same access rules as your users.

Your catalog, your brand

Each customer gets their own address, such as acme.alloycatalog.com, with their own name, logo and accent colour.

Performance

Fast on real catalogs

Security and trust

Your data stays yours

  • Read-only. Alloy Catalog never writes to your CAD files or ERP.
  • Provenance on every fact. You can always see which file or record a value came from.
  • Data stored in the EU.
  • Single sign-on with Microsoft Entra ID, with roles for readers and reviewers.
  • Private AI. Model calls go to zero-data-retention endpoints, EU first. Your data is not used for training.
  • Scoped access for API and agent integrations.
